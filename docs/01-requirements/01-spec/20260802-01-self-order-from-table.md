# 20260802-01 - ระบบสั่ง Order จากโต๊ะโดยลูกค้า (Self-Order from Table)

- **ประเภท:** Feature
- **สถานะเอกสาร:** Draft
- **วันที่สร้าง:** 2026-08-02

## ขอบเขต (Scope)

**อยู่ในขอบเขต (In scope)**

- ลูกค้าสแกน QR Code ประจำโต๊ะ เพื่อเปิดหน้าเมนูที่ผูกกับหมายเลขโต๊ะนั้นโดยอัตโนมัติ โดย**ไม่ต้อง login**
- ลูกค้าเลือกเมนู เพิ่มลงตะกร้า ปรับจำนวน แล้วกด submit order ได้เอง
- รองรับการชำระเงิน **สองช่องทาง** ให้ลูกค้าเลือก:
  - จ่ายล่วงหน้าผ่านระบบ (เช่น PromptPay/QR Payment) ก่อน order ถูกส่งเข้าครัว
  - สั่งก่อน แล้วจ่ายที่เคาน์เตอร์/ให้พนักงานเก็บเงินภายหลัง
- เมื่อลูกค้ากด submit order (และชำระเงินสำเร็จ ในกรณีเลือกจ่ายล่วงหน้า) ระบบต้อง**ส่ง order เข้าคิวครัว/KDS ทันทีโดยอัตโนมัติ** ไม่ต้องรอพนักงานตรวจสอบ/อนุมัติก่อน
- การแสดงสถานะ order เบื้องต้นให้ลูกค้าเห็น (เช่น รอดำเนินการ/กำลังทำ/เสร็จแล้ว)

**นอกขอบเขต (Out of scope) — เฟสนี้**

- ระบบสมาชิก/loyalty program
- ระบบจองโต๊ะล่วงหน้า
- การชำระเงินแบบผ่อนชำระ หรือรับบัตรเครดิตเต็มรูปแบบ
- การจัดการหลายสาขา (multi-branch)
- ระบบแจ้งเตือนลูกค้าแบบ push notification (ใช้การแสดงสถานะในหน้าเว็บแทนในเฟสนี้)

## รายละเอียด (Description)

ลูกค้าที่นั่งโต๊ะในร้านสแกน QR Code ที่ติดอยู่ประจำโต๊ะ ระบบจะเปิดหน้าเมนูออนไลน์พร้อมอ้างอิงหมายเลขโต๊ะโดยอัตโนมัติ ลูกค้าเลือกเมนู ใส่ตะกร้า และเลือกวิธีชำระเงิน (จ่ายก่อน หรือจ่ายทีหลัง) จากนั้นกด submit เพื่อส่ง order เข้าคิวครัว/บาริสต้าทันที โดยไม่ต้องผ่านการตรวจสอบจากพนักงานก่อน

## เงื่อนไข/กติกาทางธุรกิจ (Business Rules)

1. QR Code หนึ่งชุดผูกกับโต๊ะเดียวเท่านั้น (1 QR : 1 โต๊ะ)
2. หนึ่งโต๊ะสามารถสั่ง order เพิ่มได้หลายรอบระหว่างการนั่งในร้าน (ไม่จำกัดจำนวนครั้ง)
3. ราคาที่แสดงในหน้าเมนูต้องตรงกับราคาหน้าร้าน ณ เวลาที่ลูกค้าสั่ง
4. กรณีเลือก "จ่ายล่วงหน้า" ระบบต้องได้รับการยืนยันชำระเงินสำเร็จก่อน จึงจะส่ง order เข้าคิวครัวได้
5. กรณีเลือก "จ่ายทีหลัง" order จะถูกส่งเข้าคิวครัวทันทีหลังกด submit โดยยังไม่มีการชำระเงิน

## Acceptance Criteria

- [ ] ลูกค้าสแกน QR แล้วเห็นเมนูพร้อมหมายเลขโต๊ะที่ถูกต้อง โดยไม่ถูกขอให้ login
- [ ] ลูกค้าเลือกเมนู+จำนวน แล้วเห็นตะกร้าคำนวณราคารวมถูกต้อง
- [ ] ลูกค้าเลือกวิธีชำระเงินได้ทั้งสองแบบ (จ่ายก่อน/จ่ายทีหลัง)
- [ ] เมื่อ submit order (และชำระเงินสำเร็จถ้าเลือกจ่ายก่อน) order ปรากฏในคิวครัว/KDS ทันทีโดยไม่ต้องรอการอนุมัติ
- [ ] ลูกค้าสามารถดูสถานะ order ของตนเองได้หลัง submit

## ข้อสมมติฐาน/การตัดสินใจที่ยืนยันแล้ว (Confirmed Decisions)

ยืนยันกับผู้ใช้งานแล้วเมื่อ 2026-08-02:

- วิธีเข้าถึงระบบ: สแกน QR Code ประจำโต๊ะ ไม่ต้อง login
- การชำระเงิน: รองรับทั้งจ่ายล่วงหน้าและจ่ายทีหลัง ให้ลูกค้าเลือกเอง
- การส่ง order: ส่งเข้าคิวครัว/KDS ทันทีอัตโนมัติ ไม่ต้องมีพนักงานตรวจสอบก่อน

## จุดที่ยังไม่ได้ระบุ / ควรยืนยันเพิ่มเติม (Open Points)

รายการต่อไปนี้เป็นสิ่งที่ยังไม่ได้สอบถามในรอบนี้ แนะนำให้ยืนยันก่อนเข้าสู่ขั้นตอนออกแบบ (02-design):

- การปรับแต่งเมนู (เช่น ระดับความหวาน/ขนาดแก้ว/ท็อปปิ้งเพิ่ม) จำเป็นในเฟสแรกหรือไม่
- นโยบายการยกเลิก/แก้ไข order หลังจาก submit ไปแล้ว (เช่น ยกเลิกได้ภายในกี่นาที)
- ส่วนลด/โปรโมชั่น/คูปอง อยู่ในขอบเขตเฟสนี้หรือไม่
- วิธีแจ้งลูกค้าเมื่อของเสร็จ (เช่น เลขคิวบนหน้าจอ, เสียงเรียก, หรือแค่สถานะในหน้าเว็บ)
- ผู้ให้บริการชำระเงินล่วงหน้า (payment gateway) ที่จะใช้ (เช่น PromptPay ธนาคารใด, 2C2P, Omise ฯลฯ)

## ความสัมพันธ์กับเอกสารอื่น

เอกสารนี้เป็นเอกสาร requirement ฉบับแรกของโปรเจกต์ ยังไม่มี requirement อื่นให้ตรวจสอบการซ้ำซ้อน — จึงสร้างเป็นเอกสารใหม่
